# Govorun PC — форк

Голосовой ввод на русском для **Windows**. Полностью офлайн, звук никуда не уходит.

Форк [NoWor1989/Govorun-PC](https://github.com/NoWor1989/Govorun-PC), который сам является
десктопным портом Android-приложения [govorun-lite](https://github.com/amidexe/govorun-lite).

Под капотом: GigaAM v2 (Сбер, MIT) + sherpa-onnx (Apache 2.0) + xlm-roberta пунктуация (Apache 2.0)

## Чем этот форк отличается

### Длинные диктовки больше не разваливаются

Главное изменение. GigaAM обучена на сегментах примерно до 25 секунд, а оригинал
отправлял в модель всю запись одним куском. На длинных диктовках качество падало
тем сильнее, чем дальше от начала: первые фразы читаемые, последние — каша.

Теперь запись анализируется по громкости и режется на фрагменты до 18 секунд
по паузам между фразами. Порог тишины подбирается под конкретную запись, а не
задан константой, поэтому работает и при фоновом шуме. Если внятных пауз нет —
режет по длине. Побочный эффект: обработка стала быстрее реального времени,
потому что несколько мелких тензоров считаются лучше одного гигантского.

### Текст невозможно потерять

Раньше при любой ошибке распознавания текст молча обнулялся. Теперь распознанное
пишется в `~/.govorun/history.txt` и `last.txt` **до** попытки вставки, а сама
вставка возвращает признак успеха. Не вставилось — программа скажет, что текст
лежит в буфере, и где искать копию.

### Словарь замен

GigaAM обучена под русский и латиницу не выдаёт: «Warhammer» у неё всегда
«вархамер», «Notion» — «ноушн». Файл `replacements.txt` задаёт, как такие слова
писать на самом деле. В комплекте 229 правил: рабочий софт, компании и железо,
Agile-лексика, 3D-печать, умный дом.

Учитывает склонение: правило `ноушн = Notion` срабатывает и на «в ноушене».
Окончания берутся из закрытого списка, поэтому «стим» не ловит «стимул».
Файл перечитывается на лету — правки применяются без перезапуска.

### Остальное

- **Видно, что происходит.** Бейдж в углу не исчезает после остановки, а
  показывает `⏳ 3/7` — номер обрабатываемого фрагмента. Рядом полоска громкости
  микрофона: сразу понятно, слышит он вас или пишет тишину
- **Esc отменяет запись.** Перехватывается только во время записи
- **Настройки переживают перезапуск** — `config.json`. Микрофон запоминается
  по имени, а не по номеру: номера съезжают, стоит переткнуть наушники
- **Не срезает первые слова** — пауза между открытием микрофона и появлением
  бейджа, плюс низкая задержка потока
- **Потоков по числу ядер**, а не жёстко четыре
- **Починены пробелы после точек** — в оригинале предложения склеивались
  в «чудеса.Там леший бродит»

## Установка

```bash
pip install -r requirements.txt
python download_models.py
python govorun_pc.py
```

Зависимости те же, что в оригинале — ничего нового не добавилось.

## Использование

| Действие | Результат |
|---|---|
| **Alt+X** | Начать запись |
| **Alt+X** ещё раз | Остановить, распознать, вставить |
| **Esc** | Отменить запись |
| Правый клик по иконке в трее | Настройки / Выход |

## Файлы рядом с программой

| Файл | Что это |
|---|---|
| `config.json` | Хоткей, микрофон, пунктуация. Создаётся сам, в репозиторий не коммитится |
| `replacements.txt` | Словарь замен. Правится руками, перечитывается на лету |
| `~/.govorun/history.txt` | Все распознанные тексты с отметками времени |
| `~/.govorun/last.txt` | Последний распознанный текст |
